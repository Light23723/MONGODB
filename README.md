##Les Bases de Donnees SQL et NOSQL

1️⃣ C'est quoi MongoDB ? ^
MongoDB est une Base de données non relationnelle. 

On distingue: 
🗃️ MongoDB Server - le serveur.

📑 Mongo Shell - en ligne de commande.

🖼️ Mongo DB Compass - le GUI ( interface graphique).

📲 MongoDB Atlas - la version cloud en ligne.

2️⃣ La différence entre les BD relationnelles ( SQL ) et non relationnelles ( NOSQL ) ?
Les NoSQL n'ont pas schémas à respecter ; sont flexibles , pas besoin de structures hors les SQL sont bien structurés; respectent des schémas précis.

✅Créer et manipuler des collections ,  des documents, des fields... 

✅ Faire des opérations de CRUD (  create , read, update , delete).

✅ Utiliser des opérateurs( $eq, $gt...), des filtres...

✅ Faire la MAJ des données ( $set, $unset
✅ Transformer une BD SQL en BD NoSQL.
